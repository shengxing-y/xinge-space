# 心歌随录

**Xinge Space · `xinge-space` · 当前版本 `0.3.1`**

心歌的个人网站项目，当前实现本地手记、绘画与音乐记录，以及公开只读静态导出。经历、求职简历、项目案例与 GitHub 名片属于后续规划，尚未实现。

源码不包含个人数据库、日记、媒体备份或已经导出的 `site/`。版本历史见 [version.md](version.md)，维护方法见 [CONTRIBUTING.md](CONTRIBUTING.md)，使用前请阅读 [SECURITY.md](SECURITY.md)。

应用代码尚未选择开源许可证；星表派生数据单独遵循 [CC BY-SA 4.0](SKY-CATALOG-LICENSE.md)。

一个仅在本机运行的个人手记网站。晨昏双主题：黄昏长庚（Vesper）对应较明亮的暮色模式，西侧金星、暮蓝灰紫天空、玫瑰赭色余光与暖金纸墨；黎明前启明（Dawn）对应冷夜读模式，近黑墨蓝、银青强调、霜白文字和低光泽卡面。恒星按山西忻州城区朝辽宁沈阳方向（真方位约64.1°）及当前中国日期的晨昏时刻投影；金星保留为左右两侧的交互例外，不是这一观测方向的实际金星星历。画作卡片带画框装裱，瀑布流布局；带"回声"（往年今日）与"岁时记"（年度创作热力图）。工作札记、画画手册、生活碎片和私人日记。

## 打开

安装 Python 3.10 或更高版本后，双击 `start.cmd`，在浏览器打开 **http://127.0.0.1:18271**。不需要安装额外依赖。关闭运行窗口停止服务。

手机访问：让手机连上**和电脑同一个 WiFi**，启动时命令行窗口会打印一行「局域网」地址（形如 `http://192.168.x.x:18271`），手机浏览器直接打开即可。页面已做手机适配（窄屏自动单列、热力图只显示近 5 个月）。首次开放网络时 Windows 可能弹出防火墙授权提示，点「允许」。

也可以在此目录执行 `python server.py`。想恢复"仅本机可访问"，启动前设环境变量 `JOURNAL_BIND=127.0.0.1`。

## 使用

- 单击或轻触顶栏下方的金星，切换“黄昏长庚·明亮／黎明前启明·暗黑”。天空以弧形星轨换场，纸面、文字与控件约 3.6 秒缓慢渐染。金星平时不显示按钮边框，悬停或聚焦时显示轻提示；桌面可用 Tab 聚焦、Enter 或空格切换。主题记忆保存在当前浏览器，开启“减少动态效果”时立即切换、不播放星轨动画。
- 星空待机最多 20 FPS，金星光晕预绘复用。支持 View Transitions 的浏览器在切换时只捕获新旧画面，由合成层完成约 3.6 秒淡化和星轨旋转，不逐帧重绘全页颜色或 Canvas；旧浏览器使用轻量背景淡化。后台、模态窗口或缩放／滚动会收束换场；开启“减少动态效果”后立即切换，静置不重绘。
- “记一笔”新增记录，可填写日期、正文、标签并附一张图片（最多 8 MB）。
- 点击卡片查看全文，支持编辑和删除；带图的记录以全屏画廊灯箱打开，可左右切换（←/→ 键、两侧箭头），Esc 或点击背景关闭。
- 画画条目可填写媒介（水彩/水墨/油画等）与尺寸，随作品信息一并展示在画廊中。
- 首页"回声"条展示往年今日的旧记录（私人日记不会出现在这里），点击直达；页尾"岁时记"热力图呈现近一年每天的创作密度，悬停任意格子即时显示日期与篇数，并统计"近一年 N 篇 · 活跃 M 天"。
- 支持关键词搜索与月份筛选；个人名片可配置介绍与 B 站主页。
- 页脚导出 JSON 备份包含所有记录、图片、私人日记和个人名片。导入时合并记录，相同编号用备份覆盖；验证失败会回滚整次导入。
- 初次启动包含两篇明确标注的示例记录，可以编辑或删除。没有虚构个人画作、私人日记或 B 站账号。

## 发布到公网（只读展示版）

本地服务**不要**直接暴露公网（无账号密码，日记会泄露）。正确姿势：导出静态站 → 免费托管。

```bash
python export_static.py
```

导出 `site/` 目录（工作、画画、生活，**私人日记绝不导出**；样式脚本数据全内嵌进 index.html，画作图片在 site/images/）。双击 `site/index.html` 可先本地预览。

托管（推荐 Cloudflare Pages，免费、国内可访问、无需 git）：

1. 注册 [Cloudflare](https://dash.cloudflare.com) 账号（邮箱即可，免费）
2. 左侧 **Workers & Pages → Create application → Pages → Upload assets**
3. 项目名随意（如 `xinge-journal`）→ 把 `site` **文件夹整体拖进**上传窗口 → Deploy
4. 几秒后得到公网地址：`https://xinge-journal.pages.dev`
5. 以后更新内容：先在本地跑 `python export_static.py`，再回到 Pages 项目上传新的 `site` 覆盖

备选：GitHub Pages（免费，但国内访问不稳定）；想要个性域名可 later 买一个（约 ¥55/年）在 Pages 里绑定。

## 恒星图的观测参数与边界

- 观测参考点：忻州城区 **38.4177°N, 112.7335°E**；朝向沈阳 **41.8057°N, 123.4315°E**，初始大圆真方位角 **64.114°**（东北偏东），视轴仰角35°。
- 按 **UTC+8中国自然日**：黄昏取太阳中心下降至−6°，黎明前取上升至−12°。日期变化后更新；观测参数仅保留在本文档，不在首页展示。不是打开页面时的实时星空。
- 恒星来自 [HYG v4.1](https://github.com/astronexus/HYG-Database/tree/main/hyg)，使用六等以内5070颗恒星子集，按J2000赤经赤纬岁差至观测日期，再做地平坐标与等比透视投影，只绘制视野内、地平线上方的恒星。黄昏仅绘制较亮星，手机裁切视野，不拉伸或随机补星。
- 恒星位置不随鼠标移动；只有低幅度亮度闪烁。金星是主题入口例外，换场星轨为时间流转意象，并非完整天象录像。
- 不模拟当地山体、天气、消光、精细大气折射、章动／光行差与恒星自行，不能代替精密观测软件。参考 [USNO 地平坐标说明](https://aa.usno.navy.mil/faq/alt_az)。
- 星表派生数据采用 **CC BY-SA 4.0**，署名与修改记录见 [SKY-CATALOG-LICENSE.md](SKY-CATALOG-LICENSE.md)；该许可不自动覆盖文章、媒体或应用代码。
- 独立 Astronomy Engine 交叉验证：2026年6个季节代表日期、两种晨昏时刻最大误差约3.4秒；所测亮星几何高度／方位最大差约0.082°。这是一组验收结果，不是任意日期和天体的精度保证。

## 数据与隐私

数据保存在本目录 `data/journal.sqlite3`，关闭浏览器或服务不会丢失。手记数据不依赖浏览器缓存；页面通过 CDN 加载文楷字体，离线时使用系统字体回退，没有外部图片或统计请求。点击 B 站链接会访问 B 站。

服务默认监听所有网卡（本机 + 同一 WiFi 下的手机），没有账号、登录或数据库加密。同一局域网内的任何设备都能打开全部内容，包括私人日记。请勿在不可信的网络环境（公司/公共 WiFi）运行；只在自家网络使用，或设 `JOURNAL_BIND=127.0.0.1` 恢复仅本机。任何能访问此电脑和项目文件的人也都可能看到日记。备份同样包含私人数据，请妥善保管。不要把运行目录、数据库或备份上传到公开托管。

可在停止服务后复制整个 `data` 目录作为额外备份。浏览器预览与日常使用请固定使用同一地址。

后续升级可以沿用分类和 JSON 数据格式，添加经历、项目案例、登录、服务端权限和独立图片存储。当前支持导出只读展示版，不支持直接部署本地编辑服务。
